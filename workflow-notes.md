Explaination of Github objects
issues provide what work needs to be finished and what the acceptance criteria for it is. Branches can be used in relation to the issue to isolate the changes made to be viewed later if it meets the acceptance criteria inorder to merge. Commits are really important in this instance because using meaningful titles can help people reviewing your pull request to understand the changes you made. Once the branch meets the acceptance criteria you make a pull request outlining what you have gotten done and how they meet the criteria. Then someone will review your pull request to make sure it is good to merge with the default or main branch.
